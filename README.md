# Dungeon Travelers 2 — Russian text tools

Инструменты и техническая документация для русского текста в
**Dungeon Travelers 2: The Royal Library & The Monster Seal** (PC, ENG 1.0).

Репозиторий **не содержит** файлов игры, шрифтов, скриптов и перевода —
только код и документация. Всё собирается из вашей легальной копии игры.

## Что сделано

Полный отчёт по реверсу движка: [docs/ENGINE_RU.md](docs/ENGINE_RU.md)


- 112 скриптов с диалогами переведены на русский (порт из Vita-перевода).
- Кириллица встроена в атласы шрифтов движка; коды символов сохранены.
- Найдена и устранена причина «наезда» букв: движок ставит глифы по метрикам
  английского шрифта. Исправлено статическим патчем `DT2_en.exe`:
  собственный курсор строки в `FindGlyph`, без DLL/ASI.

Технические детали и адреса — в [docs/REVERSE_RU.md](docs/REVERSE_RU.md)
(English: [docs/REVERSE_EN.md](docs/REVERSE_EN.md)).

## Установка результата

1. Резервная копия `Data\ENG` и `DT2_en.exe`.
2. Распаковать архив русификатора в папку игры с заменой.
3. Запустить `DT2_en.exe`.

## Сборка патча (из своей копии)

```
python tools/port_pc.py            # порт скриптов Vita -> PC (нужны исходники перевода)
python tools/inject_ru.py          # вставка кириллицы в Font1.pck / Font2.pck
python tools/patch_static.py       # статический патч DT2_en.exe (секция .rufix)
```

`tools/build_all.bat` — сборка 32-битных `hookfont.dll`/`injector.exe`
(вариант с DLL-хуком, для отладки; в поставке не нужен).

## Требования

- Windows, Python 3 (Pillow, numpy), MSVC Build Tools (x86) — только для сборки.
- Игра: PC-версия 1.0 (`DT2_en.exe`, 2 697 728 байт). Патч привязан к адресам
  этой сборки.

## Правовой статус

Игра и её ресурсы — собственность правообладателей. Перевод текста —
работа Menori Co. (Vita). В репозитории нет ни ресурсов игры, ни перевода.
Не распространяйте собранные архивы с ресурсами игры.
