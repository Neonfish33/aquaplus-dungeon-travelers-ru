# Aquaplus Dungeon Travelers 2 — RU localization tools

Русский текст для **Dungeon Travelers 2: The Royal Library & The Monster Seal**
(PC, ENG 1.0). Репозиторий содержит только инструменты и документацию — без
файлов игры, шрифтов и перевода. Всё собирается из вашей легальной копии.

## Документация

| Файл | Что внутри |
|---|---|
| [docs/PROJECT_MAP_RU.md](docs/PROJECT_MAP_RU.md) | состав проекта, форматы, что умеем раскладывать, план Android |
| [docs/ENGINE_RU.md](docs/ENGINE_RU.md) | подробный реверс: адреса, функции, шрифты, `.rufix`, проверки |
| [docs/ENGINE_ACTIONS_RU.md](docs/ENGINE_ACTIONS_RU.md) | карта «действие → адрес/класс», опкоды, семейства классов |

## Что сделано

- 112 скриптов с диалогами переведены на русский; переносы строк — из перевода.
- Сохранены **3 байта ID говорящего** в начале текстовых чанков (иначе движок
  съедает первые буквы и ломает плашки имён).
- Переведены имена/описания: 20 файлов `Data\ENG\Parameter\*.bin` (строки
  дописаны в конец, указатели пропатчены; оригиналы в `Parameter_orig`).
- Кириллица встроена в `Font1.pck` / `Font2.pck`; коды символов сохранены.
- Раскладка исправлена статическим патчем `DT2_en.exe`: секция `.rufix`,
  собственный курсор строки в `FindGlyph`, отступ 22 px. Без DLL/ASI.

Ограничения: часть плашек имён — латиницей (имя лежит отдельной строкой
скрипта); титры интро и логотип меню — графика/видео; покрытие `Parameter`
неполное; ширины символов задаёт стаб (поле `+8` таблиц `UI.tex/UI2.tex` —
не advance, проверено маркерами в памяти).

## Установка

1. Бэкап `Data\ENG` и `DT2_en.exe`.
2. Распаковать архив русификатора в папку игры с заменой.
3. Запустить `DT2_en.exe`.

## Сборка

```
python tools/pack_ru.py       # перевод диалогов -> Data\ENG\Script (ID говорящих сохраняются)
python tools/pack_param.py    # имена/описания -> Data\ENG\Parameter (оригиналы в Parameter_orig)
python tools/inject_ru.py     # кириллица в Font1.pck / Font2.pck
python tools/patch_static.py  # статический патч DT2_en.exe (секция .rufix)
```

| Файл | Роль |
|---|---|
| `tools/translit.py` | таблица кириллица → ASCII-коды шрифта (общая для упаковщиков) |
| `tools/port_pc.py` | библиотека PCK (`parse`/`build`), нужна `pack_ru.py`; отдельным шагом не запускается |
| `tools/hookfont.cpp` | dev-вариант DLL-хука + эталон `g_w[256]` |
| `tools/injector.cpp`, `tools/build_all.bat` | сборка 32-битного инжектора (только для отладки) |

## Требования

- Windows, Python 3 (Pillow, numpy); MSVC Build Tools (x86) — только для dev-DLL.
- Игра: PC 1.0 (`DT2_en.exe`, 2 697 728 байт), патч привязан к её адресам.
- Файлы перевода (не входят в репозиторий): `перевод/translation_template.ru.csv`,
  `перевод/parameter.ru.tsv`; шрифт `C:\Windows\Fonts\arialbd.ttf`.
