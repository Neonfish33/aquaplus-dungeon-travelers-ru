# Dungeon Travelers 2 — Russian text tools

Инструменты и техническая документация для русского текста в
**Dungeon Travelers 2: The Royal Library & The Monster Seal** (PC, ENG 1.0).

Репозиторий **не содержит** файлов игры, шрифтов, скриптов и перевода —
только код и документация. Всё собирается из вашей легальной копии игры.

## Что сделано

Полный отчёт по реверсу движка: [docs/ENGINE_RU.md](docs/ENGINE_RU.md)


- 112 скриптов с диалогами переведены на русский (полный перевод проекта),
  переносы строк сохранены из перевода.
- Сохранены 3 байта ID говорящего в начале каждого текстового чанка — без них
  движок съедал первые буквы, а плашки имён ломались.
- Переведены имена, описания предметов/навыков/классов: 13 файлов
  `Data\ENG\Parameter\*.bin` (строки дописаны в конец, указатели таблиц
  пропатчены; оригиналы — в `Parameter_orig`).
- Кириллица встроена в атласы шрифтов движка; коды символов сохранены.
- Найдена и устранена причина «наезда» букв и разного левого отступа: движок
  ставит глифы по метрикам английского шрифта. Исправлено статическим патчем
  `DT2_en.exe` (секция `.rufix`, собственный курсор строки в `FindGlyph`,
  левый отступ 22 px), без DLL/ASI.

Известные ограничения: плашки имён некоторых персонажей остаются латиницей
(имя берётся из отдельной строки скрипта), тексты в видео/запечённых текстурах
(титры интро, логотип меню) не переводятся, покрытие `Parameter` неполное.
Ширины символов задаёт патч-стаб: поле `+8` таблиц `UI.tex/UI2.tex` оказалось
не advance (проверено маркерами в памяти) — движок считает шаг в коде.

Технические детали и адреса — в [docs/REVERSE_RU.md](docs/REVERSE_RU.md)
(English: [docs/REVERSE_EN.md](docs/REVERSE_EN.md)).

## Установка результата

1. Резервная копия `Data\ENG` и `DT2_en.exe`.
2. Распаковать архив русификатора в папку игры с заменой.
3. Запустить `DT2_en.exe`.

## Сборка патча (из своей копии)

```
python tools/port_pc.py            # порт скриптов Vita -> PC (нужны исходники перевода)
python tools/pack_ru.py            # перевод диалогов -> Data\ENG\Script (ID говорящих сохраняются)
python tools/pack_param.py         # имена/описания -> Data\ENG\Parameter (оригиналы в Parameter_orig)
python tools/inject_ru.py          # вставка кириллицы в Font1.pck / Font2.pck
python tools/patch_static.py       # статический патч DT2_en.exe (секция .rufix)
```

`tools/translit.py` — таблица транслитерации (кириллица -> ASCII-коды шрифта).
`tools/build_all.bat` — сборка 32-битных `hookfont.dll`/`injector.exe`
(вариант с DLL-хуком, для отладки; в поставке не нужен).

## Требования

- Windows, Python 3 (Pillow, numpy), MSVC Build Tools (x86) — только для сборки.
- Игра: PC-версия 1.0 (`DT2_en.exe`, 2 697 728 байт). Патч привязан к адресам
  этой сборки.

## Правовой статус

Игра и её ресурсы — собственность правообладателей. Перевод текста выполнен
участниками проекта. В репозитории нет ни ресурсов игры, ни перевода.
Не распространяйте собранные архивы с ресурсами игры.
